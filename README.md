Architecture

In the customer-facing website of Travlr Getaways, I have utilized Express, HTML, JavaScript and HandleBars. In addition, I have also developed an administrator Single-Page Application (SPA) utilizing Angular. Angular has the ability to allow user interaction with the application without needing to reload each page continuously. For this reason, I chose to utilize MongoDB due to the flexible document structure allowing JSON data storage and easy management of trip-related data.

Functionality

JavaScript is a programming language while JSON is a method of transferring data from the front-end to back-end. During the creation of the project, I converted static HTML into HandleBars templates and used reusable Angular components and services. These actions allowed me to reduce duplicated code within the application making it more manageable.

Testing

I tested GET, POST, and PUT endpoints in order to retrieve, create and update trip related information in MongoDB using Postman. Once I added JWT authentication to test for valid and invalid tokens became much harder. Testing validated that authenticated requests worked successfully while unauthorized requests failed.

Reflection

The course assisted me in understanding how all three layers; Frontend, Backend, Database interact with one another. The biggest obstacle I experienced throughout the use of Angular was likely due to its being my first-time exposure to Angular as well as many times encountering syntax issues or compiler errors. With my increased experience of debugging, API's and full-stack development I believe I am now prepared to continue pursuing my desired career in software development.
